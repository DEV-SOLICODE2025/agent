# Skill: Frontend Motion Design (Product-Level UI)

## Objective
Enhance frontend with modern motion and product-level UX using JavaScript animation (Framer Motion or equivalent).

---

## Rules

- Use Framer Motion for:
  - Page transitions
  - Card hover animations
  - Modal transitions
  - Sidebar slide-in/out
- Animations ≤ 300ms
- Use subtle easing (easeInOut)
- No heavy or distracting animation
- Respect performance

---

## Mandatory Motion Use Cases

- Fade-in list items
- Stagger animation on product grid
- Smooth modal open/close
- Hover scale effect (1.02 max)
- Button tap feedback

---

## UI Enhancement Requirements

- Dashboard cards with animated counters
- Smooth route transitions
- Animated loading skeletons
- Animated empty states

---

## Performance Rule

- Use lazy loading for heavy components.
- Avoid animation on large lists (>50 items).
- Respect mobile performance.
