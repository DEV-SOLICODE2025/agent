# Senior Quality & Security Standards (Full Stack & Agent)

This document defines the mandatory standards for any project generated by the agent.

---

## 1. Clean Code Architecture

### 1.1 Backend (Laravel)

- Single Responsibility Principle:  
  Controllers must NOT contain business logic.

- No Fat Controllers:  
  Maximum 200 lines per controller.

- Service Layer Mandatory:  
  All business logic must be placed inside `app/Services`.

- Validation must use FormRequest classes.

- No unsafe raw SQL.  
  Use Eloquent or secure Query Builder.

- Mass Assignment protection required (`$fillable` / `$guarded`).

- Eager Loading required to prevent N+1 queries.

---

### 1.2 Frontend (React)

- Atomic Design mandatory:
  - Components
  - Molecules
  - Organisms
  - Pages

- No API logic inside UI components.

- Centralize API calls inside:
  `src/services/`

- Any component repeated more than twice must be reusable.

- Clear state management, no duplicated state.

---

## 2. Backend Security (Critical)

- CSRF protection must be enabled.
- Server-side validation mandatory.
- All inputs must be sanitized.
- Secure hashing (bcrypt / argon2).
- Authorization via Policies / Gates.
- Rate limiting on sensitive routes.
- No sensitive data in logs.
- No exposed secrets.

---

## 3. Frontend Security

- No sensitive tokens stored in localStorage.
- Prefer HTTP-only cookies when applicable.
- Any `target="_blank"` link must include:
  `rel="noopener noreferrer"`
- No API keys exposed in frontend.
- No `dangerouslySetInnerHTML` without proper sanitation.

---

## 4. Performance & Scalability

### Backend

- Index frequently filtered columns.
- Pagination mandatory for large datasets.
- Cache frequently accessed data.
- Avoid unnecessary queries.

### Frontend

- Lazy load pages.
- Use code splitting.
- Optimize images.
- Avoid unnecessary dependencies.

---

## 5. UI/UX Quality

- Consistent spacing (4px scale system).
- Minimum WCAG AA accessibility.
- Mobile-first responsive design.
- No accidental horizontal scroll.
- Animations ≤ 300ms.

---

## 6. Agent Discipline (Mandatory)

The agent must:

- Never start coding before analysis is validated.
- Strictly follow defined workflows.
- Add a trace log for every executed action.
- Refuse actions that violate standards.
- Never ignore rules to speed up execution.

---

## 7. Required Project Structure

Every generated project must follow:

backend/
  app/
  Services/
  Http/
  Models/
  routes/

frontend/
  src/
    components/
    pages/
    services/

docs/
  analysis/
  architecture/
  decisions/

---

## 8. Absolute Prohibitions

- No duplicated code.
- No console.log in production.
- Never commit .env files.
- No unresolved TODOs.
- No unjustified dependencies.
